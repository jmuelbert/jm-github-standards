---
title: Accessibility
description: Accessibility goals and how to report barriers in jm-homebrew-qt-installer.
---

If you encounter an accessibility barrier in this project’s documentation or
tools, [open an issue](https://github.com/jmuelbert/jm-github-standards/issues/new/choose)
and select the **Accessibility** issue type.

We aim to make the project’s documentation and tools usable by as many people as
possible. When contributing, use clear headings and descriptive links, and report
any accessibility barriers you find.
